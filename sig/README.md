# RBS sig files (benchmark workload for ruby/rbs)

This `sig/` directory is **not maintained type signatures** for GitLab.
It is a static-analysis snapshot generated by [`rbs prototype rb`][1] from
`app/` and `lib/`, used as a large workload for benchmarking the
[ruby/rbs][2] resolver on Ruby 4.0+.

[1]: https://github.com/ruby/rbs/blob/master/docs/CLI.md#rbs-prototype
[2]: https://github.com/ruby/rbs

## Why this exists

`conference-app` (about 160 `.rbs` files) is too small to surface the
performance differential of resolver-side optimizations. GitLab's
`app/` + `lib/` provides a much larger workload — currently:

- 9,674 source `.rb` files
- 11,188 generated `.rbs` files (about 45 MB)
- around 39k declarations / 88k members for the resolver to process

The signatures are intentionally rough (`untyped` everywhere); the goal
is to exercise resolver code paths, not to type-check GitLab.

## Quickstart

```bash
# 1. Clone shallow (only app/lib/config are needed)
git clone --depth=1 --filter=blob:none --no-checkout https://github.com/tk0miya/gitlabhq.git
cd gitlabhq
git sparse-checkout init --no-cone
git sparse-checkout set app lib config Gemfile Gemfile.lock sig
git checkout rbs-benchmark-sigs

# 2. Run the benchmark using a checkout of ruby/rbs at any branch.
#    (We bypass `bundle exec` because GitLab's Gemfile references
#    `gems/bundler-checksum` which is outside this sparse checkout.)
RBS=/path/to/rbs/checkout
ruby -I$RBS/lib -I$RBS/tmp/arm64-darwin24/stage/lib \
  -rbenchmark -rrbs \
  -e '
    loader = RBS::EnvironmentLoader.new
    loader.add(path: Pathname("sig"))
    env = RBS::Environment.from_loader(loader)
    env = env.resolve_type_names  # 1st, heavy
    20.times do
      t = Benchmark.realtime { env = env.resolve_type_names }
      puts "%.2f ms" % (t * 1000)
    end
  '
```

A more polished benchmark script lives under `bench/` in the
`bench/rbs-resolve` branch of this fork (if present).

## Regenerating the sigs

```bash
# Requires a working ruby/rbs checkout with the compiled C extension.
RBS=/path/to/rbs/checkout
cd /path/to/gitlabhq
$RBS/exe/rbs prototype rb --out-dir=sig/app --base-dir=app app
$RBS/exe/rbs prototype rb --out-dir=sig/lib --base-dir=lib lib
```

`rbs prototype rb` parses with `RubyVM::AbstractSyntaxTree`, so it
needs MRI Ruby; jruby/truffleruby will not work.

## Caveats

- These signatures contain no real type information. Method parameters
  and return types are all `untyped`. About 83% of class super clauses
  and 89% of `include` targets are relative names — by design, since
  the prototype tool does not know what other classes are in scope.
  The resolver still has to walk those, which is the point.
- Generated on Ruby 4.0.4 with `rbs` at master (June 2026). Re-run the
  regen command above if the GitLab sources or the rbs prototype tool
  change in a way that affects the signature shapes you want to
  benchmark.
- The fork uses sparse-checkout; pushing the full unshallowed history
  is intentionally not part of the workflow here.

## Numbers from the original run

`rbs/master` versus optimization branches (`bardeen` =
Namespace trie inlining, `immutable` = `equal?`-based decl reuse in
`resolve_type_names`), chained 2nd+ resolves, 10 iterations, median:

| Branch | 2nd+ wall median | 2nd+ allocations |
| --- | --- | --- |
| master | 285.69 ms | 984,050 |
| immutable alone | 270.14 ms | 499,724 (-49%) |
| bardeen alone | 256.14 ms | 844,599 (-14%) |
| bardeen + immutable | 232.81 ms (-18%) | 360,324 (-63%) |

Apple Silicon, macOS Darwin 24.6, Ruby 4.0.4 (YJIT off).
